# Bảo trì dự đoán công nghiệp

Trang web tĩnh tiếng Việt về các kỹ thuật xử lý dữ liệu trong bảo trì dự đoán công nghiệp.

## Triển khai trên Vercel

1. Đẩy thư mục này lên một GitHub repository.
2. Trong Vercel, chọn **Add New → Project**, import repository đó.
3. Framework Preset: **Other**. Không cần Build Command hay Output Directory.
4. Chọn **Deploy**.

Vercel sẽ tự động triển khai lại khi có thay đổi được đẩy lên nhánh chính.
